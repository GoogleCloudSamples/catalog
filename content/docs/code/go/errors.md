When handling a specific service error condition (such as `NotFound` or `AlreadyExists`), inspect the error specifically using `errors.Is`, `errors.As`, or `status.Code(err)`. Otherwise, wrap errors with actionable context (`fmt.Errorf("...: %w", err)`) and return them to the caller rather than logging and returning or calling `log.Fatal`, `os.Exit`, or `panic` inside sample functions.
