gRPC-based clients such as `DlpServiceClient` don't implement `IDisposable`; they share a channel pool, so samples create the client inside the sample function without disposing it. Client instances are thread-safe, so for best performance in applications, register clients as singletons with dependency injection (for example, `services.AddDlpServiceClient()`). If a client implements `IDisposable`, such as `StorageClient`, use a `using` declaration (`using var client = ...`) to dispose of it when the method returns.
