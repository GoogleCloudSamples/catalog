The **Cloud Samples Catalog** is the curated collection of code snippets, API operation samples, and multi-file application patterns that help developers learn and build with Google Cloud. Published across Google Cloud product documentation and the [Google Cloud Samples Browser](https://docs.cloud.google.com/docs/samples), these samples span Python, Node.js, Java, Go, C#, Ruby, PHP, Terraform, and more.

This site is the central hub for **sample designers, authors, maintainers, and reviewers** who build and maintain the catalog.

## Our Approach to Sample Engineering {#approach}

Great code samples do more than compile—they help developers succeed quickly and confidently. Every sample in the catalog is guided by three core practices:

* **Teach Through Code:** Each sample focuses on a single, well-defined cloud use case and includes clear comments explaining *why* recommended patterns are used.
* **Idiomatic Yet Consistent:** Samples follow the style conventions and tooling of each language community while maintaining consistent structure, copy-paste-callable functions, and predictable error handling across languages.
* **Governed & Maintainable:** Samples are treated as long-lived technical assets backed by co-located [metadata](docs/effective-samples/metadata.md) and automated integration tests so they stay reliable as APIs and client libraries evolve.
