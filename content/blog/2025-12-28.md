## Resources with read-only names

Not all Cloud API resources allow you to specify a resource name. In those cases, a name is auto-generated for you by the service.

This can be a bit tricky. How do you retrieve a resource when you don't have its name?

Your options are:
* Inspect the resource `create` response and record the name
* Use a `list` call to see what resources are available, find the one you need, and extract the name

This means you need to be able to recognize which of potentially many resources are the one you need. That is where creation date, configuration values, and most importantly, the **Display Name** comes in handy. Specify a memorable and specific Display name to distinguish that newly created resource.

This [sample on creating a Data Transfer Configuration](https://github.com/GoogleCloudSamples/client-library-samples/blob/a2f50414bcac63137d3519d315001802ddf9aee9/bigquerydatatransfer/v1/nodejs/google-cloud-bigquery-data-transfer/data-transfer-service-client-transfer-config-create.js) shows how to specify a displayName and print out the resource name assigned by the BigQuery Data Transfer service.

The display name you use could be a temporary text just to recognize the resource. Once you have the resource name, you can use an [`update` operation to change the Display Name](https://github.com/GoogleCloudSamples/client-library-samples/blob/a2f50414bcac63137d3519d315001802ddf9aee9/bigquerydatatransfer/v1/nodejs/google-cloud-bigquery-data-transfer/data-transfer-service-client-transfer-config-update.js) to match another format.
