## Release Notes

This month we added **42 new samples** and updated **93 existing samples** across **7 languages** (C#, Go, Java, Node.js, Python, Ruby, and Terraform) in the Samples Catalog.

### New Sample Coverage

* **Generative AI** (Go, Node.js — 19 new samples): Migrated 18 Node.js generative AI snippets to the unified `@google/genai` SDK and added a Go context cache retrieval sample ([`countTokens.js`](https://github.com/GoogleCloudPlatform/nodejs-docs-samples/blob/main/generative-ai/snippets/count-tokens/countTokens.js), [`contentcache_get.go`](https://github.com/GoogleCloudPlatform/golang-samples/blob/main/genai/content_cache/contentcache_get.go)).
* **Cloud Storage Control** (Node.js — 7 new samples): Added samples for creating, updating, pausing, resuming, and inspecting **Anywhere Cache** instances ([`createAnywhereCache.js`](https://github.com/GoogleCloudPlatform/nodejs-docs-samples/blob/main/storage-control/createAnywhereCache.js)).
* **Cloud Bigtable** (Go — 4 new samples): Added cell, column, column family, and row deletion snippets ([`delete_from_column.go`](https://github.com/GoogleCloudPlatform/golang-samples/blob/main/bigtable/deletes/delete_from_column.go)).
* **Cloud Storage** (C# — 3 new samples): Added samples for setting, listing, and retrieving custom **Object Contexts** ([`GetObjectContexts.cs`](https://github.com/GoogleCloudPlatform/dotnet-docs-samples/blob/main/storage/api/Storage.Samples/GetObjectContexts.cs)).
* **Dataplex** (Python — 2 new samples): Added samples for creating global data quality and data profile scans ([`create_data_quality_scan_global.py`](https://github.com/GoogleCloudPlatform/python-docs-samples/blob/main/dataplex/snippets/create_data_quality_scan_global.py)).
* **Network Security** (Terraform — 2 new samples): Added project-level packet intercept and traffic mirroring configurations ([`network_security/intercept/project/consumer/main.tf`](https://github.com/terraform-google-modules/terraform-docs-samples/blob/main/network_security/intercept/project/consumer/main.tf)).
* **Pub/Sub** (C# — 2 new samples): Added samples for creating and updating topics and subscriptions with **Single Message Transforms (SMTs)** ([`CreateSubscriptionWithSingleMessageTransform.cs`](https://github.com/GoogleCloudPlatform/dotnet-docs-samples/blob/main/pubsub/api/Pubsub.Samples/CreateSubscriptionWithSingleMessageTransform.cs)).
* **Security Command Center** (Java — 1 new sample): Migrated Security Command Center finding management snippets into `security-command-center` without deprecated `setReadTime` calls ([`FindingSnippets.java`](https://github.com/GoogleCloudPlatform/java-docs-samples/blob/main/security-command-center/snippets/src/main/java/com/example/securitycenter/FindingSnippets.java)).
* **BigQuery** (Java — 1 new sample): Added a standardized `SimpleQuery` snippet and integration test ([`SimpleQuery.java`](https://github.com/GoogleCloudPlatform/java-docs-samples/blob/main/bigquery/cloud-client/snippets/src/main/java/com/example/bigquery/SimpleQuery.java)).
* **Spanner** (Node.js — 1 new sample): Migrated the Spanner quickstart sample to the current client surface ([`quickstart.js`](https://github.com/GoogleCloudPlatform/nodejs-docs-samples/blob/main/spanner/quickstart.js)).

### Sample Updates & Modernization

* **Generative AI** (Node.js, Python — 75 updated samples): Upgraded Gemini model IDs across 66 Python `genai` snippets and migrated 9 Node.js function-calling and multimodal snippets to `@google/genai` ([`batchpredict_with_bq.py`](https://github.com/GoogleCloudPlatform/python-docs-samples/blob/main/genai/batch_prediction/batchpredict_with_bq.py), [`functionCallingBasic.js`](https://github.com/GoogleCloudPlatform/nodejs-docs-samples/blob/main/generative-ai/snippets/function-calling/functionCallingBasic.js)).
* **Security Command Center** (Go, Java, Node.js, Terraform — 11 updated samples): Updated finding list filters, standardized region tags, and refreshed notification configurations ([`listFindingsAtTime.js`](https://github.com/GoogleCloudPlatform/nodejs-docs-samples/blob/main/security-center/snippets/v1/listFindingsAtTime.js)).
* **Cloud Run** (Java, Ruby — 2 updated samples): Migrated Java manual logging from Logstash to Cloud Logging Logback and updated Ruby Sinatra/Rack dependencies for Ruby 4.0 ([`App.java`](https://github.com/GoogleCloudPlatform/java-docs-samples/blob/main/run/logging-manual/src/main/java/com/example/cloudrun/App.java)).
* **Cloud Storage** (C# — 1 updated sample): Updated object composition sample to demonstrate deleting source objects after compose ([`ComposeObject.cs`](https://github.com/GoogleCloudPlatform/dotnet-docs-samples/blob/main/storage/api/Storage.Samples/ComposeObject.cs)).
* **Cloud Run Functions** (Node.js — 1 updated sample): Replaced deprecated `@slack/events-api` middleware with native Node.js `crypto` request signature verification ([`functions/slack/index.js`](https://github.com/GoogleCloudPlatform/nodejs-docs-samples/blob/main/functions/slack/index.js)).
* **Contact Center Insights** (Node.js — 1 updated sample): Improved conversation readiness handling in analysis creation ([`createAnalysis.js`](https://github.com/GoogleCloudPlatform/nodejs-docs-samples/blob/main/contact-center-insights/createAnalysis.js)).
* **Firestore** (Go — 1 updated sample): Updated Enterprise database client initialization in pipeline query snippets ([`pipeline_snippets_general.go`](https://github.com/GoogleCloudPlatform/golang-samples/blob/main/firestore/pipeline_snippets_general.go)).
* **Getting Started** (Go — 1 updated sample): Enabled `HttpOnly` on session cookies to harden against cross-site scripting ([`getting-started/sessions/main.go`](https://github.com/GoogleCloudPlatform/golang-samples/blob/main/getting-started/sessions/main.go)).
