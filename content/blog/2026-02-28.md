## Release Notes

This month we added **95 new samples** and updated **44 existing samples** across **6 languages** (C#, Go, Java, Node.js, Python, and Terraform) in the Samples Catalog.

### New Sample Coverage

* **Generative AI** (C#, Python — 33 new samples): Added multimodal code execution samples in Python and expanded C# Google GenAI SDK coverage across text generation, controlled generation, and provisioned throughput ([`codeexecution_annotateimage_with_txt_gcsimg.py`](https://github.com/GoogleCloudPlatform/python-docs-samples/blob/main/genai/code_execution/codeexecution_annotateimage_with_txt_gcsimg.py)).
* **Secret Manager** (Node.js, Python — 27 new samples): Onboarded copy-paste-callable Secret Manager samples and metadata in `GoogleCloudSamples/client-library-samples` covering secret creation, Pub/Sub notifications, rotation, and version lifecycle management ([`secret-manager-client-secret-create-notifications.js`](https://github.com/GoogleCloudSamples/client-library-samples/blob/main/secretmanager/v1/nodejs/google-cloud-secret-manager/secret-manager-client-secret-create-notifications.js)).
* **Cloud KMS** (Go, Java, Python — 12 new samples): Added cross-language samples for deleting `CryptoKey` and `CryptoKeyVersion` resources and inspecting `RetiredResources` ([`delete_key.py`](https://github.com/GoogleCloudPlatform/python-docs-samples/blob/main/kms/snippets/delete_key.py)).
* **Authentication** (Python — 5 new samples): Migrated canonical Application Default Credentials (ADC) and explicit authentication samples from `googleapis/google-auth-library-python` ([`authenticate_explicit_with_adc.py`](https://github.com/GoogleCloudPlatform/python-docs-samples/blob/main/auth/cloud-client-temp/authenticate_explicit_with_adc.py)).
* **Cloud Logging** (Python — 5 new samples): Migrated log sink export and structured logging samples from `googleapis/python-logging` ([`export.py`](https://github.com/GoogleCloudPlatform/python-docs-samples/blob/main/logging/samples/snippets/export.py)).
* **App Engine** (Java — 3 new samples): Upgraded Datastore and Cloud Bigtable standard environment samples from Java 8 to Java 21 ([`ListPeopleServlet.java`](https://github.com/GoogleCloudPlatform/java-docs-samples/blob/main/appengine-java21/ee8/datastore/src/main/java/com/example/appengine/ListPeopleServlet.java)).
* **Cloud SQL** (Terraform — 2 new samples): Added configurations for managing PostgreSQL and MySQL users with database roles ([`cloud_sql/mysql_user_db_role/main.tf`](https://github.com/terraform-google-modules/terraform-docs-samples/blob/main/cloud_sql/mysql_user_db_role/main.tf)).
* **Network Connectivity** (Terraform — 2 new samples): Added multicloud data transfer and Data Transfer Essentials configurations ([`network_connectivity/data_transfer_essentials/main.tf`](https://github.com/terraform-google-modules/terraform-docs-samples/blob/main/network_connectivity/data_transfer_essentials/main.tf)).
* **Compute Engine** (Terraform — 1 new sample): Added regional managed instance group (RMIG) instance flexibility policy configuration with minimum CPU platform and disk overrides ([`compute/rmig_instance_flexibility_policy/min_cpu_platform_and_disk_override/main.tf`](https://github.com/terraform-google-modules/terraform-docs-samples/blob/main/compute/rmig_instance_flexibility_policy/min_cpu_platform_and_disk_override/main.tf)).
* **BigQuery** (Python — 1 new sample): Migrated `db-dtypes` pandas date and time conversion snippets ([`pandas_date_and_time.py`](https://github.com/GoogleCloudPlatform/python-docs-samples/blob/main/bigquery/python-db-dtypes-pandas/snippets/pandas_date_and_time.py)).
* **Cloud Run** (Java — 1 new sample): Added authenticated service-to-service request verification sample ([`Authentication.java`](https://github.com/GoogleCloudPlatform/java-docs-samples/blob/main/run/service-auth/src/main/java/com/example/serviceauth/Authentication.java)).
* **Firestore in Datastore Mode** (Python — 1 new sample): Migrated core entity and query snippets from `googleapis/python-datastore` ([`snippets.py`](https://github.com/GoogleCloudPlatform/python-docs-samples/blob/main/datastore/samples/snippets/snippets.py)).
* **Google Kubernetes Engine** (Terraform — 1 new sample): Added regional cluster configuration enabling GKE Managed OpenTelemetry ([`gke/standard/regional/managed_opentelemetry/main.tf`](https://github.com/terraform-google-modules/terraform-docs-samples/blob/main/gke/standard/regional/managed_opentelemetry/main.tf)).
* **Spanner** (C# — 1 new sample): Added transaction `ReadLockMode` configuration sample ([`ReadLockModeAsync.cs`](https://github.com/GoogleCloudPlatform/dotnet-docs-samples/blob/main/spanner/api/Spanner.Samples/ReadLockModeAsync.cs)).
