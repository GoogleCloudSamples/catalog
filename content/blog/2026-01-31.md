## Release Notes

This month we added **43 new samples** and updated **24 existing samples** across **6 languages** (C#, Java, Node.js, PHP, Python, and Terraform) in the Samples Catalog.

### New Sample Coverage

* **Cloud Storage Control** (Node.js, Python — 26 new samples): Added initial `GoogleCloudSamples/client-library-samples` coverage for managing **Anywhere Cache** instances, folders, managed folders, and storage intelligence configurations ([`storage-control-client-anywhere-cache-get.js`](https://github.com/GoogleCloudSamples/client-library-samples/blob/main/storagecontrol/v2/nodejs/google-cloud-storage-control/storage-control-client-anywhere-cache-get.js)).
* **Generative AI** (Java — 6 new samples): Added **Gemini Live API** samples demonstrating real-time bidirectional audio and text streaming sessions ([`LiveAudioWithTxt.java`](https://github.com/GoogleCloudPlatform/java-docs-samples/blob/main/genai/snippets/src/main/java/genai/live/LiveAudioWithTxt.java)).
* **Cloud SQL** (Terraform — 6 new samples): Added configurations for creating and restoring Cloud SQL instances using **Backup and DR** backups ([`cloud_sql/mysql_instance_backupdr_backup/main.tf`](https://github.com/terraform-google-modules/terraform-docs-samples/blob/main/cloud_sql/mysql_instance_backupdr_backup/main.tf)).
* **Cloud Storage** (C#, PHP — 2 new samples): Added bucket listing with partial success (`returnPartialSuccess`) to handle unreachable regions gracefully ([`ListBucketsWithPartialSuccess.cs`](https://github.com/GoogleCloudPlatform/dotnet-docs-samples/blob/main/storage/api/Storage.Samples/ListBucketsWithPartialSuccess.cs)).
* **Pub/Sub** (PHP — 2 new samples): Added samples for creating topics and subscriptions with **Single Message Transforms (SMTs)** ([`create_subscription_with_smt.php`](https://github.com/GoogleCloudPlatform/php-docs-samples/blob/main/pubsub/api/src/create_subscription_with_smt.php)).
* **Eventarc** (Terraform — 1 new sample): Added end-to-end **Eventarc Advanced** bus and pipeline provisioning ([`eventarc/advanced/main.tf`](https://github.com/terraform-google-modules/terraform-docs-samples/blob/main/eventarc/advanced/main.tf)).

### Sample Updates & Modernization

* **BigQuery** (Terraform — 13 updated samples): Standardized `deletion_protection` settings across BigLake and BigQuery table samples ([`bigquery/biglake/bigquery_create_object_table/main.tf`](https://github.com/terraform-google-modules/terraform-docs-samples/blob/main/bigquery/biglake/bigquery_create_object_table/main.tf)).
* **Generative AI** (Java, Python — 4 updated samples): Upgraded video generation samples to **Veo 3.1** for video extension, updated reference-to-video aspect ratio settings, and refreshed virtual try-on models ([`videogen_with_vid.py`](https://github.com/GoogleCloudPlatform/python-docs-samples/blob/main/genai/video_generation/videogen_with_vid.py)).
* **Cloud SQL** (Terraform — 3 updated samples): Enabled `deletion_protection = true` by default in foundational Cloud SQL database instance configurations ([`cloud_sql/mysql_database_instance/main.tf`](https://github.com/terraform-google-modules/terraform-docs-samples/blob/main/cloud_sql/mysql_database_instance/main.tf)).
* **Cloud Vision** (Node.js, Python — 2 updated samples): Refreshed logo detection sample inputs and assertions ([`detect.py`](https://github.com/GoogleCloudPlatform/python-docs-samples/blob/main/vision/snippets/detect/detect.py)).
* **Eventarc** (Terraform — 1 updated sample): Scoped IAM bindings to specific resources rather than project-wide roles in Pub/Sub trigger setups ([`eventarc/basic_pubsub/main.tf`](https://github.com/terraform-google-modules/terraform-docs-samples/blob/main/eventarc/basic_pubsub/main.tf)).
* **Cloud Composer** (Python — 1 updated sample): Clarified migration script usage and documentation ([`composer_migrate.py`](https://github.com/GoogleCloudPlatform/python-docs-samples/blob/main/composer/tools/composer_migrate.py)).
