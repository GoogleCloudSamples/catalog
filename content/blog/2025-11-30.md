## Release Notes

This month we added **55 new samples** and updated **36 existing samples** across **7 languages** (C#, Go, Java, Node.js, PHP, Python, and Terraform) in the Samples Catalog.

### New Sample Coverage

* **BigQuery Data Policy** (Node.js, Python — 30 new samples): Onboarded `v1` and `v2` data masking policy creation, grantee assignment, and listing samples in `GoogleCloudSamples/client-library-samples` ([`data-policy-service-client-data-policies-list-async.js`](https://github.com/GoogleCloudSamples/client-library-samples/blob/main/bigquerydatapolicy/v1/nodejs/google-cloud-bigquery-datapolicies/v2/data-policy-service-client-data-policies-list-async.js)).
* **Generative AI** (C#, Go, Node.js, Python — 17 new samples): Added **Imagen 4** image upscaling samples and cross-language **Gemini Live API** real-time session samples ([`imggen_upscale_with_img.py`](https://github.com/GoogleCloudPlatform/python-docs-samples/blob/main/genai/image_generation/imggen_upscale_with_img.py)).
* **Pub/Sub** (Go — 3 new samples): Added managed data ingestion topic creation samples for **Amazon MSK**, **Confluent Cloud**, and **Azure Event Hubs** ([`create_topic_aws_msk_ingestion.go`](https://github.com/GoogleCloudPlatform/golang-samples/blob/main/pubsub/topics/create_topic_aws_msk_ingestion.go)).
* **App Engine** (Java — 2 new samples): Added App Engine Standard Environment samples targeting **Java 25** and Jakarta EE 11 ([`AnalyticsServlet.java`](https://github.com/GoogleCloudPlatform/java-docs-samples/blob/main/appengine-java25/ee11/analytics/src/main/java/com/example/appengine/analytics/AnalyticsServlet.java)).
* **Cloud Storage** (Go — 1 new sample): Added concurrent chunked object download sample using the Transfer Manager ([`download_chunks_concurrently.go`](https://github.com/GoogleCloudPlatform/golang-samples/blob/main/storage/transfer_manager/download_chunks_concurrently.go)).
* **Compute Engine** (Terraform — 1 new sample): Added configuration demonstrating how to disable Compute Engine preview features ([`compute/preview_feature/disable/main.tf`](https://github.com/terraform-google-modules/terraform-docs-samples/blob/main/compute/preview_feature/disable/main.tf)).
* **Spanner** (Go — 1 new sample): Added sample demonstrating large mutation payload inserts within request size limits ([`spanner_insert_large_data.go`](https://github.com/GoogleCloudPlatform/golang-samples/blob/main/spanner/spanner_snippets/spanner/spanner_insert_large_data.go)).

### Sample Updates & Modernization

* **Cloud Vision** (PHP — 24 updated samples): Migrated Cloud Vision detection and product search samples to the current GAPIC v2 client library surface ([`quickstart.php`](https://github.com/GoogleCloudPlatform/php-docs-samples/blob/main/vision/quickstart.php)).
* **Generative AI** (Node.js, Python — 8 updated samples): Upgraded video generation samples to latest **Veo** models (including first-to-last frame interpolation) and refreshed image generation model IDs ([`videogen_with_first_last_frame.py`](https://github.com/GoogleCloudPlatform/python-docs-samples/blob/main/genai/video_generation/videogen_with_first_last_frame.py)).
* **Cloud Storage** (PHP — 1 updated sample): Updated `move_object_atomic` to support standard buckets alongside hierarchical namespace buckets ([`move_object_atomic.php`](https://github.com/GoogleCloudPlatform/php-docs-samples/blob/main/storage/src/move_object_atomic.php)).
* **Cloud Speech-to-Text** (Python — 1 updated sample): Added streaming input duration limit handling to the v2 infinite microphone transcription sample ([`transcribe_streaming_infinite_v2.py`](https://github.com/GoogleCloudPlatform/python-docs-samples/blob/main/speech/microphone/transcribe_streaming_infinite_v2.py)).
* **Secret Manager** (Go — 1 updated sample): Clarified IAM tag binding prerequisites in regional secret creation ([`create_regional_secret_with_tags.go`](https://github.com/GoogleCloudPlatform/golang-samples/blob/main/secretmanager/regional_samples/create_regional_secret_with_tags.go)).
* **reCAPTCHA Enterprise** (Java — 1 updated sample): Fixed credential encoding in password leak detection assessments ([`CreatePasswordLeakAssessment.java`](https://github.com/GoogleCloudPlatform/java-docs-samples/blob/main/recaptcha_enterprise/snippets/src/main/java/recaptcha/passwordleak/CreatePasswordLeakAssessment.java)).
