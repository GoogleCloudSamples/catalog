## Release Notes

This month we added **239 new samples** and updated **55 existing samples** across **8 languages** (C#, Go, Java, Node.js, PHP, Python, Ruby, and Terraform) in the Samples Catalog.

### New Sample Coverage

* **Cloud Storage** (C#, Python — 153 new samples): Consolidated 149 Python Cloud Storage snippets from `googleapis/python-storage` into `python-docs-samples` and added C# Anywhere Cache management samples ([`quickstart.py`](https://github.com/GoogleCloudPlatform/python-docs-samples/blob/main/storage/samples/snippets/quickstart.py)).
* **Spanner** (C#, Node.js, PHP — 53 new samples): Migrated core Node.js Spanner CRUD, schema, indexing, and transaction samples and added C# and PHP transaction snippets ([`crud.js`](https://github.com/GoogleCloudPlatform/nodejs-docs-samples/blob/main/spanner/crud.js)).
* **Firestore** (Go — 11 new samples): Added pipeline query snippets covering stages, accumulators, aggregations, and vector search ([`pipeline_snippets_accumulators_aggregation.go`](https://github.com/GoogleCloudPlatform/golang-samples/blob/main/firestore/pipeline_snippets_accumulators_aggregation.go)).
* **Storage Batch Operations** (C# — 8 new samples): Added samples for creating, listing, inspecting, and canceling Storage Batch Operations jobs ([`CancelBatchJob.cs`](https://github.com/GoogleCloudPlatform/dotnet-docs-samples/blob/main/storagebatchoperations/api/StorageBatchOperations.Samples/CancelBatchJob.cs)).
* **Vertex AI Search for Commerce** (Java, Python — 6 new samples): Added retail catalog search snippets covering pagination offsets, filtering, and query expansion ([`search_offset.py`](https://github.com/GoogleCloudPlatform/python-docs-samples/blob/main/retail/snippets/search_offset.py)).
* **BigQuery** (Python, Terraform — 3 new samples): Added a BigFrames Python UDF invocation sample and Terraform configurations for BigQuery reservation groups and autoscaling reservations ([`call_python_udf.py`](https://github.com/GoogleCloudPlatform/python-docs-samples/blob/main/bigquery/bigframes/call_python_udf.py)).
* **Cloud Run** (Python — 2 new samples): Added OpenTelemetry instrumentation setup for a Cloud Run Model Context Protocol (MCP) server ([`otel_setup.py`](https://github.com/GoogleCloudPlatform/python-docs-samples/blob/main/run/mcp-server/otel_setup.py)).
* **Workflows** (Java — 2 new samples): Added samples for executing workflows with and without runtime arguments ([`ExecuteWithArguments.java`](https://github.com/GoogleCloudPlatform/java-docs-samples/blob/main/workflows/cloud-client/src/main/java/com/example/workflows/ExecuteWithArguments.java)).
* **Workload Identity** (Terraform — 1 new sample): Added configuration for generating service agents and binding IAM policies ([`workloadidentity/generate_service_agents/main.tf`](https://github.com/terraform-google-modules/terraform-docs-samples/blob/main/workloadidentity/generate_service_agents/main.tf)).

### Sample Updates & Modernization

* **Cloud Healthcare API** (Node.js — 11 updated samples): Standardized `json` response types and IAM policy request payloads across DICOM and FHIR samples ([`importDicomInstance.js`](https://github.com/GoogleCloudPlatform/nodejs-docs-samples/blob/main/healthcare/dicom/importDicomInstance.js)).
* **Cloud Run Functions** (Node.js, Python, Ruby — 10 updated samples): Replaced deprecated `gm` / ImageMagick dependencies with `sharp` in Node.js image-processing functions and removed legacy Stackdriver references in Python OCR functions ([`functions/ocr/app/main.py`](https://github.com/GoogleCloudPlatform/python-docs-samples/blob/main/functions/ocr/app/main.py)).
* **Parameter Manager** (C#, Go, Java, Node.js, Python — 10 updated samples): Clarified version rendering guidance and `GetParameterVersion` usage across global and regional Parameter Manager snippets ([`render_regional_param_version.py`](https://github.com/GoogleCloudPlatform/python-docs-samples/blob/main/parametermanager/snippets/regional_samples/render_regional_param_version.py)).
* **Spanner** (Ruby — 7 updated samples): Updated gem dependencies and configuration for Ruby 4.0 compatibility ([`database_leader_placement_samples.rb`](https://github.com/GoogleCloudPlatform/ruby-docs-samples/blob/main/spanner/database_leader_placement_samples.rb)).
* **Cloud Composer** (Python — 4 updated samples): Corrected task naming in GKE Operator DAG samples ([`gke_operator.py`](https://github.com/GoogleCloudPlatform/python-docs-samples/blob/main/composer/airflow_1_samples/gke_operator.py)).
* **Generative AI** (Go, Java — 4 updated samples): Upgraded image generation and virtual try-on samples to current model versions ([`ImageGenVirtualTryOnWithTextAndImage.java`](https://github.com/GoogleCloudPlatform/java-docs-samples/blob/main/genai/snippets/src/main/java/genai/imagegeneration/ImageGenVirtualTryOnWithTextAndImage.java)).
* **Cloud Run** (Node.js — 2 updated samples): Migrated the image-processing service from `gm` to `sharp` ([`image.js`](https://github.com/GoogleCloudPlatform/nodejs-docs-samples/blob/main/run/image-processing/image.js)).
* **Cloud Storage** (C# — 1 updated sample): Generalized object move sample to work across all bucket configurations ([`MoveObject.cs`](https://github.com/GoogleCloudPlatform/dotnet-docs-samples/blob/main/storage/api/Storage.Samples/MoveObject.cs)).
* **Cloud Monitoring** (Python — 1 updated sample): Replaced legacy Stackdriver terminology in resource listing snippets ([`list_resources.py`](https://github.com/GoogleCloudPlatform/python-docs-samples/blob/main/monitoring/api/v3/api-client/list_resources.py)).
* **Cloud SQL** (Terraform — 1 updated sample): Updated SQL Server read pool configuration to use SQL Server 2022 and Private Service Access ([`cloud_sql/sqlserver_instance_read_pool/main.tf`](https://github.com/terraform-google-modules/terraform-docs-samples/blob/main/cloud_sql/sqlserver_instance_read_pool/main.tf)).

* **Vertex AI Search** (Python — 1 updated sample): Updated Discovery Engine conversational answer query model version ([`answer_query_sample.py`](https://github.com/GoogleCloudPlatform/python-docs-samples/blob/main/discoveryengine/answer_query_sample.py)).
* **Eventarc** (Ruby — 1 updated sample): Added Ruby 4.0 unbundled gem support ([`eventarc/generic/app.rb`](https://github.com/GoogleCloudPlatform/ruby-docs-samples/blob/main/eventarc/generic/app.rb)).
* **Media CDN** (Ruby — 1 updated sample): Updated token signing sample dependencies for Ruby 4.0 ([`dualtoken.rb`](https://github.com/GoogleCloudPlatform/ruby-docs-samples/blob/main/media_cdn/dualtoken.rb)).
