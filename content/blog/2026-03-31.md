## Release Notes

This month we added **304 new samples** and updated **45 existing samples** across **8 languages** (C#, Go, Java, Node.js, PHP, Python, Ruby, and Terraform) in the Samples Catalog.

### New Sample Coverage

* **Sensitive Data Protection (DLP)** (Node.js, Python — 60 new samples): Onboarded comprehensive `v2` inspection, de-identification template, job trigger, and risk analysis samples in `GoogleCloudSamples/client-library-samples` ([`dlp-service-client-deidentify-template-create-async.js`](https://github.com/GoogleCloudSamples/client-library-samples/blob/main/dlp/v2/nodejs/google-cloud-dlp/v6/dlp-service-client-deidentify-template-create-async.js)).
* **Secret Manager** (PHP — 34 new samples): Added regional and global secret filtering, tag binding, and version management samples ([`list_regional_secret_versions_with_filter.php`](https://github.com/GoogleCloudPlatform/php-docs-samples/blob/main/secretmanager/src/list_regional_secret_versions_with_filter.php)).
* **Document AI** (Python — 34 new samples): Onboarded `v1` and `v1beta3` processor management, document evaluation, and batch processing samples in `GoogleCloudSamples/client-library-samples` ([`documentai_v1_document_processor_service_client_evaluation_get_global.py`](https://github.com/GoogleCloudSamples/client-library-samples/blob/main/documentai/v1/python/google-cloud-documentai/documentai_v1_document_processor_service_client_evaluation_get_global.py)).
* **Cloud Run** (Node.js — 30 new samples): Added Cloud Run Admin API `v2` samples for services, jobs, executions, tasks, and worker pools in `GoogleCloudSamples/client-library-samples` ([`executions-client-execution-delete-async.js`](https://github.com/GoogleCloudSamples/client-library-samples/blob/main/cloudrun/v2/nodejs/google-cloud-run/v3/executions-client-execution-delete-async.js)).
* **Cloud Speech-to-Text** (Python — 30 new samples): Added Speech-to-Text `v1` and `v2` recognizer, custom class, and phrase set adaptation samples in `GoogleCloudSamples/client-library-samples` ([`adaptation_client_custom_class_create.py`](https://github.com/GoogleCloudSamples/client-library-samples/blob/main/speech/v1/python/google-cloud-speech/v2/adaptation_client_custom_class_create.py)).
* **Cloud Storage** (C#, Go, Node.js, PHP — 29 new samples): Migrated and modernized Node.js requester pays, Pub/Sub notification, and quickstart samples, and added cross-language bucket and object management snippets ([`disableRequesterPays.js`](https://github.com/GoogleCloudPlatform/nodejs-docs-samples/blob/main/storage/disableRequesterPays.js)).
* **Dataproc** (Python — 29 new samples): Added cluster lifecycle, autoscaling policy, batch workload, and workflow template samples in `GoogleCloudSamples/client-library-samples` ([`autoscaling_policy_service_client_autoscaling_policies_list.py`](https://github.com/GoogleCloudSamples/client-library-samples/blob/main/dataproc/v1/python/google-cloud-dataproc/v5/autoscaling_policy_service_client_autoscaling_policies_list.py)).
* **Cloud Billing Budgets** (Node.js, Python — 20 new samples): Onboarded budget creation, threshold alert, and listing samples in `GoogleCloudSamples/client-library-samples` ([`budget-service-client-budget-create-async.js`](https://github.com/GoogleCloudSamples/client-library-samples/blob/main/billingbudgets/v1/nodejs/google-cloud-billing-budgets/v6/budget-service-client-budget-create-async.js)).
* **Security Command Center & Model Armor** (Python — 14 new samples): Added **Model Armor** template, floor setting, and prompt/response sanitization samples alongside Security Command Center management snippets ([`model_armor_client_floor_setting_get.py`](https://github.com/GoogleCloudSamples/client-library-samples/blob/main/securitycenter/v1/python/google-cloud-modelarmor/v0/model_armor_client_floor_setting_get.py)).
* **BigQuery Data Policy** (Node.js, Python — 9 new samples): Added `v2` data masking policy and grantee management samples in `GoogleCloudSamples/client-library-samples` ([`data-policy-service-client-grantees-add.js`](https://github.com/GoogleCloudSamples/client-library-samples/blob/main/bigquerydatapolicy/v2/nodejs/google-cloud-bigquery-datapolicies/data-policy-service-client-grantees-add.js)).
* **Spanner** (C#, Go, PHP, Ruby — 6 new samples): Added transaction `ReadLockMode`, `LastStatement` DML option, and `BatchWrite` samples ([`spanner_read_lock_mode.go`](https://github.com/GoogleCloudPlatform/golang-samples/blob/main/spanner/spanner_snippets/spanner/spanner_read_lock_mode.go)).
* **Cloud SQL** (Terraform — 4 new samples): Added multi-region point-in-time recovery (PITR) with Backup and DR and SQL Server read pool configurations ([`cloud_sql/mysql_instance_gcbdr_mr_pitr/main.tf`](https://github.com/terraform-google-modules/terraform-docs-samples/blob/main/cloud_sql/mysql_instance_gcbdr_mr_pitr/main.tf)).
* **Dataflow** (Java — 2 new samples): Added Managed I/O JDBC read and write pipeline snippets ([`PostgresRead.java`](https://github.com/GoogleCloudPlatform/java-docs-samples/blob/main/dataflow/snippets/src/main/java/com/example/dataflow/PostgresRead.java)).
* **Authentication** (Go — 1 new sample): Added service account key validation sample ([`auth_validate_service_account_key.go`](https://github.com/GoogleCloudPlatform/golang-samples/blob/main/auth/auth_validate_service_account_key.go)).
* **BigQuery** (Terraform — 1 new sample): Added Cloud Resource connection IAM configuration ([`bigquery/bigquery_create_connection_cloud_resource/main.tf`](https://github.com/terraform-google-modules/terraform-docs-samples/blob/main/bigquery/bigquery_create_connection_cloud_resource/main.tf)).
* **Eventarc** (Terraform — 1 new sample): Added customer-managed encryption key (CMEK) configuration for Eventarc Advanced ([`eventarc/use_cmek/advanced/main.tf`](https://github.com/terraform-google-modules/terraform-docs-samples/blob/main/eventarc/use_cmek/advanced/main.tf)).
