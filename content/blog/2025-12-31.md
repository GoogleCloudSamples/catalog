## Release Notes

This month we added **197 new samples** and updated **79 existing samples** across **6 languages** (Go, Java, Node.js, PHP, Python, and Terraform) in the Samples Catalog.

### New Sample Coverage

* **Generative AI** (Go, Java, Node.js, Python — 72 new samples): Added **Google GenAI SDK** samples for preference tuning, bounding box object detection, token counting, and Google Search grounding ([`preference_tuning_job_create.py`](https://github.com/GoogleCloudPlatform/python-docs-samples/blob/main/genai/tuning/preference_tuning_job_create.py)).
* **BigQuery Reservation** (Node.js, Python — 30 new samples): Onboarded capacity commitment, reservation, reservation group, and assignment samples in `GoogleCloudSamples/client-library-samples` ([`reservation_service_client_assignment_create.py`](https://github.com/GoogleCloudSamples/client-library-samples/blob/main/bigqueryreservation/v1/python/google-cloud-bigquery-reservation/reservation_service_client_assignment_create.py)).
* **BigQuery Migration** (Node.js, Python — 24 new samples): Onboarded SQL translation and migration workflow management samples in `GoogleCloudSamples/client-library-samples` ([`migration_service_client_migration_subtask_get.py`](https://github.com/GoogleCloudSamples/client-library-samples/blob/main/bigquerymigration/v2/python/google-cloud-bigquery-migration/migration_service_client_migration_subtask_get.py)).
* **BigQuery Data Transfer** (Node.js, Python — 22 new samples): Onboarded transfer config creation, schedule triggering, and data source discovery samples in `GoogleCloudSamples/client-library-samples` ([`data_transfer_service_client_data_source_get.py`](https://github.com/GoogleCloudSamples/client-library-samples/blob/main/bigquerydatatransfer/v1/python/google-cloud-bigquery-datatransfer/data_transfer_service_client_data_source_get.py)).
* **BigQuery Connection** (Node.js, Python — 12 new samples): Onboarded external data source connection management samples in `GoogleCloudSamples/client-library-samples` ([`connection_service_client_connection_create.py`](https://github.com/GoogleCloudSamples/client-library-samples/blob/main/bigqueryconnection/v1/python/google-cloud-bigquery-connection/connection_service_client_connection_create.py)).
* **Secret Manager** (Java, PHP — 12 new samples): Added samples for configuring and managing secrets with **delayed version destruction** ([`CreateSecretWithDelayedDestroy.java`](https://github.com/GoogleCloudPlatform/java-docs-samples/blob/main/secretmanager/src/main/java/secretmanager/CreateSecretWithDelayedDestroy.java)).
* **BigQuery Storage** (Node.js, Python — 10 new samples): Onboarded `BigQueryRead` and `BigQueryWrite` stream session samples in `GoogleCloudSamples/client-library-samples` ([`big_query_read_client_read_session_create.py`](https://github.com/GoogleCloudSamples/client-library-samples/blob/main/bigquerystorage/v1/python/google-cloud-bigquery-storage/big_query_read_client_read_session_create.py)).
* **Authentication** (Java, Node.js, Python — 6 new samples): Added custom credential supplier samples demonstrating AWS and Okta workload identity federation ([`snippets.py`](https://github.com/GoogleCloudPlatform/python-docs-samples/blob/main/auth/custom-credentials/aws/snippets.py)).
* **Cloud Storage** (Go — 6 new samples): Added samples for **Object Contexts** metadata and `ListBuckets` with `ReturnPartialSuccess` ([`list_buckets_partial_success.go`](https://github.com/GoogleCloudPlatform/golang-samples/blob/main/storage/buckets/list_buckets_partial_success.go)).
* **BigQuery** (Terraform — 2 new samples): Added configurations for creating SQL stored procedures and running query jobs ([`bigquery/bigquery_create_stored_procedure/main.tf`](https://github.com/terraform-google-modules/terraform-docs-samples/blob/main/bigquery/bigquery_create_stored_procedure/main.tf)).
* **Backup and DR** (Terraform — 1 new sample): Added backup plan association configuration for Cloud SQL instances ([`backupdr/backup_plan_association/main.tf`](https://github.com/terraform-google-modules/terraform-docs-samples/blob/main/backupdr/backup_plan_association/main.tf)).

### Sample Updates & Modernization

* **Generative AI** (Go, Java, Node.js, Python — 48 updated samples): Added domain exclusion options to Google Search grounding snippets and standardized multimodal and bounding box samples ([`tools_google_search_with_txt.py`](https://github.com/GoogleCloudPlatform/python-docs-samples/blob/main/genai/tools/tools_google_search_with_txt.py)).
* **Cloud Speech-to-Text** (PHP — 12 updated samples): Upgraded Speech-to-Text snippets to the current GAPIC v2 client surface ([`quickstart.php`](https://github.com/GoogleCloudPlatform/php-docs-samples/blob/main/speech/quickstart.php)).
* **BigQuery Data Policy** (Node.js, Python — 11 updated samples): Standardized `example-project-id` placeholders and error handling across `GoogleCloudSamples/client-library-samples` ([`data-policy-service-client-data-policies-list.js`](https://github.com/GoogleCloudSamples/client-library-samples/blob/main/bigquerydatapolicy/v2/nodejs/google-cloud-bigquery-datapolicies/data-policy-service-client-data-policies-list.js)).
* **Cloud Run** (Node.js — 5 updated samples): Upgraded HTTP client dependencies and migrated the Markdown Preview sample service to ES Modules ([`run/markdown-preview/editor/app.js`](https://github.com/GoogleCloudPlatform/nodejs-docs-samples/blob/main/run/markdown-preview/editor/app.js)).
* **Backup and DR** (Terraform — 1 updated sample): Updated backup plan resource rules to support Cloud SQL associations ([`backupdr/backup_plan/main.tf`](https://github.com/terraform-google-modules/terraform-docs-samples/blob/main/backupdr/backup_plan/main.tf)).
* **Firestore** (PHP — 1 updated sample): Migrated batch write sample to use `BulkWriter` ([`data_batch_writes.php`](https://github.com/GoogleCloudPlatform/php-docs-samples/blob/main/firestore/src/data_batch_writes.php)).
* **Pub/Sub** (PHP — 1 updated sample): Fixed push endpoint configuration in unwrapped push subscription sample ([`create_unwrapped_push_subscription.php`](https://github.com/GoogleCloudPlatform/php-docs-samples/blob/main/pubsub/api/src/create_unwrapped_push_subscription.php)).
