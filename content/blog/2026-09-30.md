## Spotlight: Grounded Answers with the Developer Knowledge API

When you're building an IDE assistant, an MCP tool for coding agents, or an internal troubleshooting bot, relying on an LLM's training weights alone often leads to hallucinated CLI flags or outdated client library methods. In September, we added cross-language samples in **Node.js**, **Go**, and **Java** for the **Developer Knowledge API**, which provides programmatic access to official Google developer documentation.

The new samples cover two distinct integration patterns depending on what you are building:

* **Direct Grounded Q&A ([`answerQuery.js`](https://github.com/GoogleCloudPlatform/nodejs-docs-samples/blob/main/developer-knowledge/answerQuery.js), [`answer_query.go`](https://github.com/GoogleCloudPlatform/golang-samples/blob/main/developerknowledge/answer_query.go))**: Best when you want the service to synthesize a ready-to-display answer complete with `citations` and source `references`.
* **Two-Stage RAG Retrieval ([`searchDocumentChunks.js`](https://github.com/GoogleCloudPlatform/nodejs-docs-samples/blob/main/developer-knowledge/searchDocumentChunks.js), [`getDocument.js`](https://github.com/GoogleCloudPlatform/nodejs-docs-samples/blob/main/developer-knowledge/getDocument.js), and [`batchGetDocuments.js`](https://github.com/GoogleCloudPlatform/nodejs-docs-samples/blob/main/developer-knowledge/batchGetDocuments.js))**: Best when your agent or pipeline needs raw documentation passages and surrounding page context to feed into its own reasoning loop.

### Extending the Samples: Chaining Chunk Search into Full-Page Context

Each catalog sample demonstrates a single API operation in isolation. In a real developer tool, however, a single documentation chunk is sometimes too narrow—you may want to search for the most relevant chunk first, and then use its `chunk.parent` resource name to fetch the full guide (for example, to check prerequisites or required IAM roles).

Here is how you can combine [`searchDocumentChunks.js`](https://github.com/GoogleCloudPlatform/nodejs-docs-samples/blob/main/developer-knowledge/searchDocumentChunks.js) and [`getDocument.js`](https://github.com/GoogleCloudPlatform/nodejs-docs-samples/blob/main/developer-knowledge/getDocument.js)—note the `{autoPaginate: false}` option on `searchDocumentChunks`, which prevents the client library from automatically paging through the entire documentation index:

```javascript
const {DeveloperKnowledgeClient} = require('@google/developer-knowledge');

const client = new DeveloperKnowledgeClient();

async function retrieveGroundedContext() {
  const request = {
    query: 'How do I create a Cloud Storage bucket?',
    pageSize: 3,
  };

  try {
    // Disable autoPaginate so the client only fetches the requested page.
    const [chunks] = await client.searchDocumentChunks(request, {
      autoPaginate: false,
    });
    if (chunks.length === 0) {
      return;
    }

    const topChunk = chunks[0];
    const [doc] = await client.getDocument({name: topChunk.parent});

    console.log(`Source: ${doc.title} (${doc.uri})`);
    console.log(`Matched passage:\n${topChunk.content}`);
  } catch (err) {
    console.error(`error: failed to retrieve developer documentation: ${err.message}`);
  }
}
```
