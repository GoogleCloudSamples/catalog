## Release Notes

This month we added **22 new samples** and updated **35 existing samples** across **6 languages** (Go, Java, Node.js, PHP, Python, and Terraform) in the Samples Catalog.

### New Sample Coverage

* **Cloud Storage** (PHP — 6 new samples): Added bucket IP filtering samples for creating, updating, and removing VPC and public CIDR access rules ([`create_bucket_ip_filtering.php`](https://github.com/GoogleCloudPlatform/php-docs-samples/blob/main/storage/src/create_bucket_ip_filtering.php)).
* **Generative AI** (Go, Java, Node.js, Python — 6 new samples): Migrated evaluation and function-calling samples from `vertexai.generative_models` to the Google GenAI SDK ([`pairwise_summarization_quality.py`](https://github.com/GoogleCloudPlatform/python-docs-samples/blob/main/genai/evaluation/pairwise_summarization_quality.py)).
* **BigQuery** (Python — 4 new samples): Added **BigFrames** query execution and BigQuery Storage integration snippets ([`query_bqstorage.py`](https://github.com/GoogleCloudPlatform/python-docs-samples/blob/main/bigquery/bigframes/query_bqstorage.py)).
* **Memorystore** (Go, Java, Node.js, Python — 4 new samples): Added cross-language samples for exporting **Memorystore for Redis** client-side metrics ([`memorystore/redis/client_side_metrics/main.py`](https://github.com/GoogleCloudPlatform/python-docs-samples/blob/main/memorystore/redis/client_side_metrics/main.py)).
* **Gemini Data Analytics** (Python — 1 new sample): Added an Agent-to-Agent (A2A) client sample for the **Data Engineering Agent** ([`dea_a2a_client.py`](https://github.com/GoogleCloudPlatform/python-docs-samples/blob/main/geminidataanalytics/dataengineeringagent/dea_a2a_client.py)).
* **Application Lifecycle Management** (Python — 1 new sample): Added UI integration example application ([`alm/ui-examples/app.py`](https://github.com/GoogleCloudPlatform/python-docs-samples/blob/main/alm/ui-examples/app.py)).

### Sample Updates & Modernization

* **Vertex AI Generative AI** (Python — 18 updated samples): Migrated Retrieval-Augmented Generation (RAG) corpus and retrieval snippets to the latest Vertex AI Agent Platform RAG module ([`create_corpus_example.py`](https://github.com/GoogleCloudPlatform/python-docs-samples/blob/main/generative_ai/rag/create_corpus_example.py)).
* **Secret Manager** (Python — 4 updated samples): Refreshed delayed secret version destruction snippets and dependencies ([`create_secret_with_delayed_destroy.py`](https://github.com/GoogleCloudPlatform/python-docs-samples/blob/main/secretmanager/snippets/create_secret_with_delayed_destroy.py)).
* **Compute Engine** (Node.js, Python — 3 updated samples): Aligned zone and global operation polling snippets with updated documentation and modernized Node.js email notification dependencies ([`wait_for_operation.py`](https://github.com/GoogleCloudPlatform/python-docs-samples/blob/main/compute/client_library/ingredients/operations/wait_for_operation.py)).
* **Cloud Storage** (PHP, Python — 2 updated samples): Updated object composition samples to support deleting source objects upon completion ([`storage_compose_file.py`](https://github.com/GoogleCloudPlatform/python-docs-samples/blob/main/storage/samples/snippets/storage_compose_file.py)).
* **Gemini Platform** (Node.js — 2 updated samples): Updated BigQuery and Cloud Storage batch prediction samples to `gemini-2.5-flash` ([`batch-predict-bq.js`](https://github.com/GoogleCloudPlatform/nodejs-docs-samples/blob/main/ai-platform/snippets/batch-prediction/batch-predict-bq.js)).
* **Vertex AI** (Java — 2 updated samples): Removed decommissioned legacy text generation region tags ([`QuestionAnswer.java`](https://github.com/GoogleCloudPlatform/java-docs-samples/blob/main/vertexai/snippets/src/main/java/vertexai/gemini/QuestionAnswer.java)).
* **Generative AI** (Java — 1 updated sample): Standardized tool and function calling description snippets ([`ToolFunctionDescriptionWithText.java`](https://github.com/GoogleCloudPlatform/java-docs-samples/blob/main/genai/snippets/src/main/java/genai/tools/ToolFunctionDescriptionWithText.java)).
* **Cloud Logging** (Python — 1 updated sample): Updated `write_entry` snippet to use standard Python `logging` integration ([`snippets.py`](https://github.com/GoogleCloudPlatform/python-docs-samples/blob/main/logging/samples/snippets/snippets.py)).
* **Google Kubernetes Engine** (Terraform — 1 updated sample): Updated zonal GPU node pool configuration to demonstrate multi-instance GPUs ([`gke/standard/zonal/gpu/main.tf`](https://github.com/terraform-google-modules/terraform-docs-samples/blob/main/gke/standard/zonal/gpu/main.tf)).
* **Sensitive Data Protection (DLP)** (Node.js — 1 updated sample): Resolved CommonJS module loading in custom hotword inspection ([`inspectWithCustomHotwords.js`](https://github.com/GoogleCloudPlatform/nodejs-docs-samples/blob/main/dlp/inspectWithCustomHotwords.js)).
