## Release Notes

This month we added **16 new samples** and updated **32 existing samples** across **7 languages** (Go, Java, Node.js, PHP, Python, Ruby, and Terraform) in the Samples Catalog.

### New Sample Coverage

* **Cloud Storage** (Node.js, PHP — 10 new samples): Added samples for **Object Contexts** metadata, bucket encryption enforcement policies, and custom client endpoint configuration ([`setClientEndpoint.js`](https://github.com/GoogleCloudPlatform/nodejs-docs-samples/blob/main/storage/setClientEndpoint.js)).
* **Spanner** (Ruby — 2 new samples): Added transaction option samples configuring read-write isolation levels ([`spanner_isolation_level.rb`](https://github.com/GoogleCloudPlatform/ruby-docs-samples/blob/main/spanner/spanner_isolation_level.rb)).
* **Generative AI** (Python — 1 new sample): Added multimodal image generation with video input using the Google GenAI SDK ([`imggen_mmflash_img_with_vid.py`](https://github.com/GoogleCloudPlatform/python-docs-samples/blob/main/genai/image_generation/imggen_mmflash_img_with_vid.py)).
* **Cloud Bigtable** (Go — 1 new sample): Added instance administration snippet demonstrating optional resource tag bindings at creation time ([`bigtable/instanceadmin/main.go`](https://github.com/GoogleCloudPlatform/golang-samples/blob/main/bigtable/instanceadmin/main.go)).
* **Firestore** (Java — 1 new sample): Added recursive collection and subcollection deletion sample ([`DeleteCollection.java`](https://github.com/GoogleCloudPlatform/java-docs-samples/blob/main/firestore/samples/src/main/java/com/example/firestore/DeleteCollection.java)).
* **Cluster Director** (Terraform — 1 new sample): Added **Hypercompute Cluster** provisioning configuration ([`hypercomputecluster/main.tf`](https://github.com/terraform-google-modules/terraform-docs-samples/blob/main/hypercomputecluster/main.tf)).

### Sample Updates & Modernization

* **Secret Manager** (PHP — 11 updated samples): Standardized coding style and formatting across regional and global Secret Manager snippets ([`create_regional_secret_with_topic.php`](https://github.com/GoogleCloudPlatform/php-docs-samples/blob/main/secretmanager/src/create_regional_secret_with_topic.php)).
* **Spanner** (PHP — 7 updated samples): Applied PER coding style formatting across Spanner snippets and generated protobuf metadata ([`User.php`](https://github.com/GoogleCloudPlatform/php-docs-samples/blob/main/spanner/generated/GPBMetadata/Data/User.php)).
* **Generative AI** (Node.js, Python — 6 updated samples): Upgraded multimodal image editing and virtual try-on (`virtual-try-on-001`) samples to GA model versions ([`imggen_mmflash_edit_img_with_txt_img.py`](https://github.com/GoogleCloudPlatform/python-docs-samples/blob/main/genai/image_generation/imggen_mmflash_edit_img_with_txt_img.py)).
* **Cloud Run** (Go — 4 updated samples): Migrated `grpc-ping` inter-service communication samples away from deprecated gRPC dial calls ([`run/grpc-ping/client/client.go`](https://github.com/GoogleCloudPlatform/golang-samples/blob/main/run/grpc-ping/client/client.go)).
* **Vertex AI** (Go — 3 updated samples): Replaced deprecated PaLM (`code-bison`, `text-bison`) model references with Gemini models and corrected multimodal streaming MIME types ([`batch_code_predict.go`](https://github.com/GoogleCloudPlatform/golang-samples/blob/main/vertexai/batch-predict/batch_code_predict.go)).
* **Dialogflow** (Java — 1 updated sample): Removed deprecated `ArticleSuggestion` usage from conversation profile management ([`ConversationProfileManagement.java`](https://github.com/GoogleCloudPlatform/java-docs-samples/blob/main/dialogflow/snippets/src/main/java/com/example/dialogflow/ConversationProfileManagement.java)).
