## Release Notes

This month we added **21 new samples** and updated **33 existing samples** across **6 languages** (C#, Go, Java, Node.js, Python, and Ruby) in the Samples Catalog.

### New Sample Coverage

* **Generative AI** (Go, Python — 10 new samples): Added **Google GenAI SDK** model tuning job management, tuning job cancellation, and code retrieval samples ([`tuning_job_cancel.py`](https://github.com/GoogleCloudPlatform/python-docs-samples/blob/main/genai/tuning/tuning_job_cancel.py)).
* **Cloud Storage** (C#, Node.js — 6 new samples): Added C# bucket IP filtering samples and Node.js object composition with source deletion ([`composeFile.js`](https://github.com/GoogleCloudPlatform/nodejs-docs-samples/blob/main/storage/composeFile.js)).
* **Developer Knowledge** (Python — 4 new samples): Added initial Python samples for the **Developer Knowledge API**, covering grounded question answering, document retrieval, and chunk search ([`answer_query.py`](https://github.com/GoogleCloudPlatform/python-docs-samples/blob/main/developer-knowledge/answer_query.py)).
* **Security Command Center** (Java — 1 new sample): Added finding and source management region tag snippets ([`SourceSnippets.java`](https://github.com/GoogleCloudPlatform/java-docs-samples/blob/main/security-command-center/snippets/src/main/java/com/example/securitycenter/SourceSnippets.java)).

### Sample Updates & Modernization

* **Gemini Platform** (C# — 20 updated samples): Upgraded multimodal summarization, function calling, and system instruction samples from `gemini-2.0-flash` to `gemini-2.5-flash` ([`AudioInputSummarization.cs`](https://github.com/GoogleCloudPlatform/dotnet-docs-samples/blob/main/aiplatform/api/AIPlatform.Samples/AudioInputSummarization.cs)).
* **Generative AI** (Java, Node.js — 8 updated samples): Migrated text-to-image and multimodal image reference samples to `gemini-2.5-flash-image` and `generateContent` ([`imggen-with-txt.js`](https://github.com/GoogleCloudPlatform/nodejs-docs-samples/blob/main/genai/image-generation/imggen-with-txt.js)).
* **Vertex AI** (Go — 2 updated samples): Removed decommissioned legacy text generation samples in favor of Gemini translation and generation snippets ([`gemini_translate.go`](https://github.com/GoogleCloudPlatform/golang-samples/blob/main/vertexai/snippets/gemini_translate.go)).
* **Cloud Storage** (Go — 1 updated sample): Updated `compose_object` sample to demonstrate deleting source objects after composition ([`compose_object.go`](https://github.com/GoogleCloudPlatform/golang-samples/blob/main/storage/objects/compose_object.go)).
* **Cloud Run Functions** (Node.js — 1 updated sample): Refactored Cloud SQL instance scheduling function and instance state lookup ([`functions/scheduleinstance/index.js`](https://github.com/GoogleCloudPlatform/nodejs-docs-samples/blob/main/functions/scheduleinstance/index.js)).
* **Cloud Talent Solution** (Ruby — 1 updated sample): Modernized job search filter sample formatting for RuboCop compliance ([`filter_search_sample.rb`](https://github.com/GoogleCloudPlatform/ruby-docs-samples/blob/main/jobs/V3/filter_search_sample.rb)).
